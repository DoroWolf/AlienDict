# 外星词典

外星词的字形（原文）与译文对照站：**一个词一页**。原文由若干外星字形拼接而成，词与词之间
靠**空格元素**（空一个字符大小）隔开，**实义词的字形都可点击**跳到它自己的解释页，
虚词用括号框住即不跳转；页面上**原文在上、译文在下**：词头左侧是放大的外星字形（不跳转）、
右侧是中英释义；正文则是上方一整块原文（多行聚在一起）、下方一整块译文（与原文逐行对应，带翻译标题）。
目录页还能**按词素找词**：点一个词素，只看由它构成的词（见「按词素找词」）。

纯静态、可离线：产物能直接双击打开，也能整包丢到任意静态托管。

## 目录

```
alien_dict/
├─ glyph/                 字形：16×16 点阵 PNG（1-bit，笔画宽 1 像素）
│  └─ svg/                同名 SVG，由 png2svg.py 生成（页面内联用）
├─ data/
│  ├─ lexicon.yaml        站点标题/描述 + 字段约定
│  └─ entries/<id>.yaml   一个词一个文件（<id>＝文件名/URL/原文引用键，与英文释义解耦；可选 notes: 上下文提示）
├─ templates/
│  ├─ base.html.j2  entry.html.j2  index.html.j2
│  └─ static/style.css  spoiler.js
├─ tools/
│  ├─ png2svg.py          点阵 PNG -> SVG（pixel 模式，逐墨点无损）
│  ├─ subset_font.py      GNU Unifont -> 只含站点用字的 woff2（5.1 MB -> 6 KB）
│  └─ build.py            校验 + 渲染 + 目录 + 检索数据 + 字库子集化
├─ assets/fonts/          GNU Unifont 源字体与授权说明
└─ site/                  产物：index.html、w/<id>.html、assets/
```

## 常用命令

```powershell
python tools/png2svg.py --all --changed     # 新画好字形后转 SVG（增量）
python tools/build.py                       # 构建站点（含字库子集化）
python tools/build.py --no-font             # 改数据时跳过子集化，快很多
python tools/build.py --only one            # 只重建某个词的页面
python tools/build.py --clean               # 先清空 site/ 再构建

python -m http.server 8000 --directory site # 本地预览（也可直接双击 index.html）
```

## 新增一个词

1. 画好 `glyph/<id>.png`（16×16、透明底、纯黑点阵），跑 `python tools/png2svg.py --all --changed`。
2. 新建 `data/entries/<id>.yaml`：
   ```yaml
   id: one
   order: 1              # 可选：字序，决定目录排序与「上一词/下一词」
   zh: 一                # 字的中译
   en: one               # 字的英文释义（与文件名/URL 无关）
   notes: ["外星人使用七进制。"]   # 可选：上下文提示，词条页正文下方的「提示」栏（见「提示（上下文）」）
   glyph: one            # 可选：字形文件名，缺省与 id 同名
   alien: ["one"]        # 原文：元素即一个词（也可写字符串 "one"）
   meanings:             # 含义
     - alien: ["one", "", "(be)", "", "number", "", "word"]   # "" ＝一个空格
       zh: 一是数词                                # 它的中译
     - alien: ["\n"]                               # 只写 "\n"＝空行分隔行（额外换一行）
     - zh: 单独写中译也可以
   ```

   原文字段的写法：
   - **列表**（标准）`["one", "", "two"]`，元素即一个词，元素 `""`＝**一格宽**的空白；
     **字符串** `"one two"` 等价（空格＝一个空位）。
   - 词与词之间**不会自动补任何符号**：要空一格就写元素 `""`；`["one","two"]` 两个字会紧挨着。
   - 元素 `"\n"`（或字符串里的换行）＝**换一行**，换行与空行都恰好占**一格高**（＝一个字符高度）。
   - `(id)` 整个词被括号框住时**只显示字形、不跳转**（虚词等功能词）；纯数字 token 同样不跳转。
     id 里自带括号的词（如 `right_(direction)`）不受影响，仍是一个词。
3. `python tools/build.py`。目录页、字形链接、上一词/下一词、检索数据、词素索引、字库子集都会自动更新。

## 按词素找词

原文里照下面的句式写，站点就会自动建立词素索引：

- `X of morpheme be A and B` —— X 由词素 A、B 构成（`of morpheme be` 是标记，`and`/`or` 只是连接词，不算词素）。
- `X be base morpheme` —— X 是基础词素。
- 句式里照旧可以写 `(符号名)`（如 `(angle_shape)`）：只显示字形、不跳转。
- 可选字段 `morphemes: [a, b]` 可显式指定词素，覆盖句式推导（句式写不下时才用）。

构建会得到「基础词素 → 由它构成的词」的反向索引，体现在两处：

- **目录页**：「按词素找词」一栏列出所有被当作词素的基础词素（词多的在前，徽章上的数字＝含此词素的词数）。
  徽章是「筛选」按钮：点一下下方目录就只剩含此词素的词 —— 由它（间接）构成的词，外加它自己
  （这个词素也有词条时，结果里那张卡片就是进它词条页的入口），再点一次取消（与搜索框的筛选可叠加）。
  这一栏可折叠（默认收起，折叠头显示词素总数）：选中词素或用深链 `index.html#m=<词素 id>` 进来时自动展开
  （词条页的「在目录里按词素找」就是这个深链）。
- **词条页**：正文下方「词素」区块 —— 上半是本词由哪些词素构成（点徽章跳词条），下半是「含此词素的词」
  （超过 12 个词时默认收起）。基础词素会标出「·基础词素」。

**词素会一路拆到基础词素**：某个词素自己还有构成词素时，就继续往里拆，直到基础词素
（原文里 `X be base morpheme`）或拆不动的（还没词条 / 没写明构成，如 `(符号名)`）。
所以徽章列的是最终的基础词素，鼠标停在徽章上会标出「经由 谁」：（平方根）= 大 + 变化 + 数量 + 二
（其中「大、变化」经由乘方、「数量、二」经由一半）。

还没词条的词素（`data/entries/<id>.yaml` 不存在）照常显示成虚线徽章、不可点，与「待补词条」一致。
构建日志里的 `[词素] …` 一行会报告基础词素总数与写明了构成词素的词数。

原文里引用到的实义词 id 若还没有对应词条，字形照常显示但不可点击（虚线标记），
并汇总到目录页底部的「待补词条」；括号框住的词与数字不算实义词，不在此列。
补齐 YAML 后重新构建即自动点亮。

## 提示（上下文）

词条里可以写 `notes:` 交代这个词的上下文（世界设定、换算关系一类），词条页正文下方会多出「提示」一栏：

```yaml
notes: 外星人使用七进制，即满七进一。           # 一段文字
notes: ["…", "…"]                             # 多段
notes:                                        # 需要小标题时
  - title: 七进制
    text: 外星人使用七进制，即满七进一。
```

- 提示**直接写在各自的 `data/entries/<id>.yaml` 里**（一个词的上下文跟着这个词走），不写就没有这一栏；
  同一个事实要在多个词条上出现，就在各自的 YAML 里各写一份。
- 提示是中文说明＝**译文性质**，渲染时标了 `data-spoiler`：防剧透开着时随其它译文一起遮住，点一下才揭开
  （原文＝字形照旧不遮）。
- 构建日志里的 `[提示] …` 一行会报告提示条数与挂了提示的词条数。
- 词条里写了空的、或不是文字/`{title, text}` 的提示会在构建时报 `[警告]`。

## 防剧透（默认开启）

译文本身就是谜底，所以站点默认**遮住译文**：

- 页头右侧有个**开关**（「防剧透：开 / 防剧透：关」）。开着时，译文/释义都糊掉 ——
  目录卡片上的中英释义、词头释义、翻译整块、词素徽章上的文字、提示栏、前后导航的词名；
  **原文（外星字形）从不遮挡**。
- 想看被糊住的内容要过一道**剧透警告**弹窗（「剧透警告 / 再想想 / 显示译文」）：确认后只揭开这一处，
  取消（或按 Esc、点背景）就维持原样；点开关关掉防剧透则弹同款警告，确认后**全站**显示译文。
- 开关状态记在浏览器 `localStorage`（键 `alien-dict-spoiler`），下次进站照旧。
  遮住时连 `title` 提示、字形上的读屏文案（`aria-label` / `alt`）以及**标签页标题**（词条页标题里带着译文，
  这时只留站点名）都一并藏好，悬停与读屏都不漏底；**没有 JS 时不遮挡**（不会把内容锁死），双击打开也能读。
- 不想要这套遮挡：`data/lexicon.yaml` 里写 `spoiler: false` 重新构建即可
  （开关、弹窗、脚本一律不输出，页面上的 `data-spoiler` 标记留着但没人理会，不影响阅读）。

自己往模板里新增译文时，标两下即可复用：`data-spoiler`（要遮的文本节点）、
`data-spoiler-title` / `data-spoiler-label`（提示与字形读屏文案里的释义），
逻辑都在 `templates/static/spoiler.js`（构建时会拷到 `site/assets/spoiler.js`）。

## 设计要点

- **原文即字形链**：`alien: ["a", "", "b"]` 渲染成 `[a] [b]`，词间靠空格元素 `""` 空一个字符大小，
  实义词逐个可点，括号框住的词与数字只显示字形不跳转。元素 `"\n"` 让原文额外换一行。
- **词素索引由原文推导，且拆到基础词素**：原文里的句式 `X of morpheme be A and B`（＝X 由词素 A、B 构成）与
  `X be base morpheme`（＝基础词素）就是词素声明的唯一来源；构建时先把每个词的词素递归拆到只剩基础词素，
  再翻成「基础词素 → 词」的反向索引。目录页的词素筛选（可折叠）与词条页的「词素」区块都是静态预渲染好的
  （徽章自带 `data-words`，含由它构成的词与该词素自己，字形内联），JS 只做隐藏/显示与开合，不用 `fetch()`，`file://` 双击可用。
- **提示跟着词条走**：上下文说明（世界设定、换算关系一类）写在词条自己的 `notes:` 里 —— 一段文字、
  多段，或 `{title, text}` 列表；词条页正文下方渲染成「提示」栏，没写就不输出这一栏。
  提示是中文说明＝译文性质，标 `data-spoiler` 随防剧透一起遮。
- **词头左右、正文上下**：词头是「左＝放大的外星字形（纯字形、不跳转）｜右＝中英释义」；
  正文是上方一整块原文（各义项的原文行依次聚在一起，多行就在一起）、下方一整块译文
  （翻译标题 + 与原文行一一对应的中译）。
- **原文按字符网格排**：`""`＝一格宽的空白；换行与空行都恰好占**一格高**（`--gl-line`，
  随字形尺寸自动缩放：正文一格 = `--gl-row`，词头 = `--gl-head`，目录卡片 = `--gl-card`），
  行与行之间不额外留缝；同一行里字符之间留 2px 的缝方便阅读。
- **id / 字形 / 英文释义解耦**：`<id>` 只作文件名与 URL，字形文件名走 `glyph`（缺省同名），
  英文释义走 `en`，三者可以各不相同。
- **字形是内联 SVG**，`fill="currentColor"` —— 明暗主题自动适配，任意放大不糊，无需两套图。
- **pixel 模式无损**：源图是 1-bit 点阵，转换只做「相邻墨点合并成矩形」，不插值不拟合（`one.png` 的 15 个墨点 → 1 个 `<rect>`）。
- **GNU Unifont 自动子集化**：正文用 Unifont（点阵字体，覆盖全部汉字），构建时扫描产物 HTML 得到精确字符集，5.1 MB 源字体裁到约 6 KB；新增词条后重新构建即可。
- **缺 SVG 时回退位图**，字形转换可分步做，站点始终可用。
- **检索用 `assets/search-index.js` 而非 JSON**：`fetch()` 在 `file://` 下会被 CORS 拦，`<script>` 不会，保证双击可开。
- **防剧透默认开启**：遮住的是译文、不遮原文（字形）；遮挡只看 `<html class="spoiler-on">` 这个类，
  由 `<head>` 里的内联脚本早于首帧加上（译文不会先闪一下），没有 JS 自然就不加＝内容照常可读。
  要遮的节点标 `data-spoiler`，含释义的提示/读屏文案标 `data-spoiler-title` / `data-spoiler-label`，
  点开先过「剧透警告」弹窗 —— 静态标记 + 一段无依赖的 `spoiler.js`，`file://` 双击可用。
- **构建可增量**：不整目录删除（Windows 下文件被占用会让全量删除中断），改成写完再清理多余产物。
