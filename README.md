# 外星词典

外星词的字形（原文）与译文对照站：**一个词一页**。原文由若干外星字形拼接而成，词与词之间
靠**空格元素**（空一个字符大小）隔开，每个词的字形都可点击跳到它自己的解释页；
页面上**原文在上、译文在下**：词头左侧是放大的外星字形（不跳转）、右侧是中英释义；
正文则是上方一整块原文（多行聚在一起）、下方一整块译文（与原文逐行对应，带翻译标题）。
目录页还能**按词素找词**：点一个词素，只看由它构成的词（见「按词素找词」）；
另有一页「**外星写作**」：上方写作、下方按含义查字，左键点字形写进去、右键点字形看它的含义（见「外星写作」）。

纯静态、可离线：产物能直接双击打开，也能整包丢到任意静态托管。

站点用 **Vue 3 + Vite** 写：构建时用 Vue 的服务端渲染把每一页**预渲染成静态 HTML**，
浏览器里再**水合**出交互（搜索、词素筛选、防剧透）；Python 只留两件事 ——
画好的字形转 SVG（`png2svg.py`）、产物字库子集化（`subset_font.py`）。

## 常用命令

```powershell
npm install                                 # 前端依赖（Vue / Vite / yaml）
npm run dev                                 # 开发服务器（HMR，页面数据是真的）
npm run build                               # 全量：客户端 + 服务端构建 + site/ + 字库子集化
npm run build:client                        # 只跑客户端构建（web/dist/client）
npm run build:ssr                           # 只跑预渲染入口构建（web/dist/server）
npm run build:site                          # 只重跑预渲染（vite 产物没变时最快）
npm run graph                               # 词素关系图（内部校对工具 → out/morpheme-graph.html）

node tools/build.mjs --only one             # 只重建某个词条的页面
node tools/build.mjs --no-font              # 跳过字库子集化（改数据时快）
node tools/build.mjs --clean                # 先清空 site/ 再构建

python tools/png2svg.py --all --changed     # 新画好字形后转 SVG（增量）
python tools/subset_font.py                 # 单独重跑字库子集化（构建里已含）

node tools/morpheme_graph.mjs               # 词素关系图 → out/morpheme-graph.html（内部校对用）
node tools/_check_graph.mjs                 # 自检上面那张图（数据 / 布局 / 渲染冒烟测试）

python -m http.server 8000 --directory site # 本地预览（也可直接双击 index.html）
```

改数据（`data/`）后跑 `npm run build:site` 即可；改了 Vue 组件 / 样式则跑 `npm run build`。

## 新增一个词

1. 画好 `glyph/<id>.png`（16×16、透明底、纯黑点阵），跑 `python tools/png2svg.py --all --changed`。
2. 新建 `data/entries/<id>.yaml`：
   ```yaml
   id: one
   order: 1              # 可选：字序，决定目录排序与「上一词/下一词」
   zh: 一                # 字的中译
   en: one               # 字的英文释义（与文件名/URL 无关）
   notes: ["外星人使用七进制。"]   # 可选：上下文提示，词条页正文下方的「提示」栏
   glyph: one            # 可选：字形文件名，缺省与 id 同名
   alien: ["one"]        # 原文：元素即一个词（也可写字符串 "one"）
   meanings:             # 含义
     - alien: ["one", "be", "numeral"]          # 原文：每个元素都是一个词
       zh: 一是数词                              # 它的中译
     - alien: ["one", "morpheme", "be", "unit"] # 「X morpheme be A and B」＝X 由词素 A、B 构成
       zh: 一由词素「单位」构成
     - alien: ["\n"]                            # 只写 "\n"＝空行分隔行（额外换一行）
     - zh: 单独写中译也可以
   ```
3. `npm run build`。目录页、字形链接、上一词/下一词、词素索引、字库子集都会自动更新。

原文字段的写法：

- **列表**（标准）`["one", "", "two"]`，元素即一个词，元素 `""`＝**一格宽**的空白；
  **字符串** `"one two"` 等价（空格＝一个空位）。
- 词与词之间**不会自动补任何符号**：要空一格就写元素 `""`；`["one","two"]` 两个字会紧挨着。
- 元素 `"\n"`（或字符串里的换行）＝**换一行**：显式换行只是另起一行、行首不补空格；
  换行与空行都恰好占**一格高**（＝一个字符高度）。
- 一行放不下时由浏览器**自动折行**：折出来的那一行**行首空一个单位**（字格里换行占掉一格）。
  这是排版行为，不用在数据里写空格：`.gl` 整行留一格左内边距，再用负缩进把**第一行**拉回原位
  （见 `web/src/styles/app.css`）。
- **每个词都是实义词**：有自己的词条就点得动，没有词条的只显示字形（虚线标记，见「待补词条」）；
  括号与纯数字都没有特殊含义 —— `(be)` 与 `be` 是同一个词，数字也照样能点（有词条的话）。

## 按词素找词

原文里照下面的句式写，站点就会自动建立词素索引：

- `X morpheme be A and B` / `X morpheme be A` —— X 由词素 A、B 构成（`and`/`or` 只是连接词，不算词素）。
  旧写法 `X of morpheme be A and B` 里的 `morpheme be` 同样命中，老数据不用改。
- `X be base morpheme` —— X 是基础词素；整行以 `X of morpheme be` 收尾（后面不跟词素）同样算基础词素。
- `X be noun`、`X be verb` 这类定义句**不算**词素声明（标记必须是 `morpheme be`）。
- 可选字段 `morphemes: [a, b]` 可显式指定词素，覆盖句式推导（句式写不下时才用）。

构建会得到「基础词素 → 由它构成的词」的反向索引，体现在两处：

- **目录页**：「按词素找词」一栏列出所有被当作词素的基础词素（词多的在前，徽章上的数字＝含此词素的词数）。
  徽章是「筛选」按钮：点一下下方目录就只剩含此词素的词 —— 由它（间接）构成的词，外加它自己
  （这个词素也有词条时，结果里那张卡片就是进它词条页的入口），再点一次取消（与搜索框的筛选可叠加）。
  徽章上**只有中译与数字，不显示英文**；悬停时的提示里才有「中译（英文）」的完整释义。
  这一栏可折叠（默认收起，折叠头显示词素总数）：选中词素或用深链 `index.html#m=<词素 id>` 进来时自动展开
  （词条页的「在目录里按词素找」就是这个深链）。
- **词条页**：正文下方「词素」区块 —— 上半是本词由哪些词素构成（点徽章跳词条），下半是「含此词素的词」
  （超过 12 个词时默认收起）。

**词素会一路拆到基础词素**：某个词素自己还有构成词素时，就继续往里拆，直到基础词素或拆不动的
（还没词条 / 没写明构成）。所以徽章列的是最终的基础词素，悬停提示里会标出「经由 谁」。

还没词条的词素照常显示成虚线徽章、不可点，与「待补词条」一致。

原文里引用到的词 id 若还没有对应词条，字形照常显示但不可点击（虚线标记），
并汇总到目录页底部的「待补词条」；补齐 YAML 后重新构建即自动点亮。

## 词素关系图（校对用，内部工具）

`node tools/morpheme_graph.mjs`（＝ `npm run graph`）把「谁由哪些词素构成」画成一张
**分层图**，产物是自包含的单文件 `out/morpheme-graph.html`（内联字形与脚本，双击就能开、
离线可用）。**这是内部工具**：不接进 `site/`、不进构建流程，`out/` 已 `.gitignore`；
语义全部复用 `tools/lib/lexicon.mjs`，与站点同一套推导。

- **怎么读**：层号＝这个词往下拆几层能拆到「不再拆分」（基础词素在第 0 层）；一条边＝一条
  「X morpheme be A and B」声明。层内顺序按字序 + 重心法（少交叉）排，一层超过 32 个就折行
  （`--per-row` 调，`0`＝不折行）。
- **操作**：搜索（中译 / 英文 / id，回车跳第一个）、命中加黄圈、点节点看它的关系网
  （蓝＝它的词素、绿＝由它构成的词）、双击只看这一片、滚轮缩放 / 拖动平移 /
  `F` 适应视图 / `Esc` 取消选中；深链 `#<id>` 直接选中某个词。
- **左栏「词条」**：字形 + 中英释义 + 每条**词素声明**（原文那句话 + 拆出的词素 + 递归到的
  基础词素）+ 义项（原文在上、中译在下）+「由它构成的词」，用来逐条核对 `data/entries/<id>.yaml`。
- **左栏「问题」**：词素声明首词不是本词 id、声明里把自己当词素、成环、被当作词素但没写构成、
  没写构成也不作别人的词素、待补词条、zh / en / 义项中译缺失、字形缺失、`morphemes` 字段——
  条目可点，点了跳到对应节点。
- **筛选**：隐藏未写构成 / 隐藏非实义 / 只看有问题 / 只看选中网络（都会重排布局）。
- **自检**：`node tools/_check_graph.mjs`（先跑一次图）。它把产物里的内联数据解出来做一致性
  断言、把布局函数单独调出来验证（不重不漏、行内不重叠、层序单调、边朝上），再用一个最小
  DOM 桩把页面脚本 `init()` 真的跑一遍（渲染 / 选中 / 点击 / 拖动 / 搜索 / 聚焦 / 筛选 / 三个页签）。

## 外星写作

页头的「写作」进写作页（`site/write.html`；词条页里是 `../write.html`）——
**上方是写作栏、下方是搜索词汇栏**，按含义拼外星文：

- **上方写作栏是固定两层**：上层是输入栏（放正在写的字形，**高度固定三行**，写满了在里面滚，
  光标一动就滚进视野），下层是一排按钮；整块 sticky 在顶部，往下翻搜索结果时它还留在眼前。
  写作内容是「词 / 空格 / 换行」三种单元的序列，**光标**是单元之间的位置（最前 / 某一格之间 / 最后）；
  **空行（连着换行换出来的）也照占一格高**，不会塌掉。
  按钮与键盘管同一件事：**左移、右移**（光标挪一格）、**空格**（在光标处空一格）、
  **换行**（在光标处另起一行）、**退格**（删掉光标左边那一格）、**清空**（清掉全部），
  右侧显示已经写的**字数**（只数字形，空格与换行不算）。
- **键盘**：`←` / `→` 移光标、`Enter` 换行、`空格` 空一格、`Backspace` 退格、`Esc` 关掉词条弹窗
  （和上面那排按钮一一对应）；焦点在搜索框里时不抢键、照常打字，用 Tab 停到按钮上时空格 / 回车归按钮自己。
  **点过字形 / 按钮之后焦点会收回写作栏**，所以接着敲的空格、回车仍然是写作栏的键
  （不然浏览器会当成「再点一次刚才那个按钮」＝又写一遍上一个字）。
- 点写作栏里的某一格＝把光标挪到这一格；**右键点某一格＝看它的词条**。
- **下方搜索词汇栏**：输入含义（中译或英文/词 id 都能命中）过滤全部词，
  排序是「完全相同 → 中译开头 → 英文开头 → 包含」，同权重按字序；**命中多少列多少，不截断**，
  只有**一个都没命中**时才提示一句。**左键点字形＝在光标处写进去**，
  **右键点字形＝弹窗看它的词条**（不写进去）。
- **右键＝词条弹窗**：字形 + 中英释义 + 各义项的原文与译文（上原文、下译文，与词条页同一套排版）
  + 「提示」；弹窗里只有词条本身（没有别的按钮），点背景或按 `Esc` 关掉。
  **弹窗里的字形也能点**：不跳页，就在这个弹窗里换成那个词的词条（在弹窗里继续看别的词，
  不会把人从写作页带走）；还没词条的词照旧不可点。**弹窗开着时写作键先不动**（在弹窗里敲键盘
  不该动到背后的写作栏），只有 `Esc` 与点背景管用。
- **译文照旧遮**：搜索结果里的中英释义、弹窗里的释义与翻译、提示都是译文，照常标 `data-spoiler`——
  防剧透开着时是糊的，点一下要先过剧透警告；**字形（原文）与写作栏从不遮挡**。
  点搜索框与目录页一样会先过一遍剧透警告（搜字是按译文找词）。
- **写作内容不落盘**：刷新即清空，也不导出文件（只是一个拼字的台子）。
- 数据在 `buildWriteProps` 里算（全部词 + 全部字形 + 每条词条内容 + 搜索词），
  预渲染成静态 HTML 后由客户端水合，交互全在本地，不发任何请求。

## 提示（上下文）

词条里可以写 `notes:` 交代这个词的上下文（世界设定、换算关系一类），词条页正文下方会多出「提示」一栏：

```yaml
notes: 外星人使用七进制，即满七进一。           # 一段文字
notes: ["…", "…"]                             # 多段
notes:                                        # 需要小标题时
  - title: 七进制
    text: 外星人使用七进制，即满七进一。
```

- 提示**直接写在各自的 `data/entries/<id>.yaml` 里**（一个词的上下文跟着这个词走），不写就没有这一栏。
- 提示是中文说明＝**译文性质**，渲染时标了 `data-spoiler`：防剧透开着时随其它译文一起遮住。
- 词条里写了空的、或不是文字/`{title, text}` 的提示会在构建时报 `[警告]`。

## 防剧透（内置）

译文本身就是谜底，所以站点**默认遮住译文**：页头右侧那个按钮显示当前状态（「防剧透：开 / 防剧透：关」），
状态记在浏览器 `localStorage`（键 `alien-dict-spoiler`），不是构建时的开关。

- 遮住的是：目录卡片上的中英释义、词头释义、翻译整块、词素徽章上的文字、提示栏、前后导航的词名；
  **原文（外星字形）从不遮挡**。
- 点某处被遮住的译文 → 过一道**剧透警告**弹窗（「剧透警告 / 再想想 / 确定」），确认后**只揭开这一处**，
  取消（或按 Esc、点背景）就维持原样。
- 遮着时点**目录页的搜索框**也会先过一遍警告（搜字是按译文找词）：确认后防剧透关掉、全站译文显示，
  之后正常打字搜索；取消就维持遮住（这一次访问里不会反复问，防剧透状态一变会重新问）。
- 点页头按钮：遮着时点它＝问一次后**全站**确定；关着时点它＝立刻遮回去（并清掉已揭开的那些）。
- **左右词条链接是例外**：它们遮着，但点一下直接跳转（不弹警告、不揭开）——
  组件上标了 `data-spoiler-direct`，由 `useSpoiler` 放行。
- **字形区点一下是「动作」，遮住的文字点一下是「揭开」**：徽章与卡片上的字形部分不被遮，
  点它直接筛选 / 跳转；被遮住的中译点一下先过警告、揭开这一处，之后再点才是动作。
- 遮住时连 `title` 提示、字形上的读屏文案（`aria-label` / `alt`）也一并藏好；
  **标签页标题**里带译文的部分只在揭开后才补上（没有 JS 时标题本来就是完整的）。
- 没有 JS 时不会加 `.spoiler-on` 这个类 ＝ 内容照常可读（不会把站点锁死），双击打开也能读。
  早于首帧的加类脚本在页面外壳里（`tools/lib/shell.mjs` ← `web/src/composables/spoilerBoot.mjs`），
  开发入口用的是同一份源码（`web/dev-plugin.mjs` 塞进 `web/index.html`）。

自己往组件里新增译文时，标三下即可复用：`data-spoiler`（要遮的文本节点）、
`data-spoiler-title` / `data-spoiler-label`（提示与字形读屏文案里的释义）、
`data-spoiler-direct`（遮着也要点得动时加它），逻辑都在 `web/src/composables/useSpoiler.js`。

## 设计要点

- **预渲染 + 水合，仍然是「一个词一个页」**：构建时用 Vue 的服务端渲染把 `App.vue` 渲染成静态 HTML
  （`site/index.html`、`site/w/<id>.html`，页头、字形链、译文、词素、前后导航全在 HTML 里），
  浏览器里同一套组件用**同一份数据**水合出交互。没有 JS 时页面照常可读，双击打开（`file://`）也能用。
- **每页只带自己那点数据**：`tools/lib/props.mjs` 为每一页算出「本页用到的词与字形」，
  `tools/build.mjs` 把它同时用于预渲染与内联（`window.__ALIEN_DICT_PROPS__`），
  客户端拿它水合，不用再请求任何接口。代价是目录页要把 580 张卡片的字形也内联一份
  （HTML ≈ 1.8 MB，其中约一半是这份水合数据），词条页约 60 KB；
  写作页要带上全部词（按含义搜索）、每条词条内容（右键弹窗用）与字形，约 1.1 MB。
- **客户端脚本是普通脚本**（Vite 打成 IIFE，不是 ES module）：`<script src="assets/app.js">`
  在 `file://` 下不会被 CORS 拦，双击就能跑。
- **原文即字形链**：`alien: ["a", "", "b"]` 渲染成 `[a] [b]`，词间靠空格元素 `""` 空一个字符大小，
  实义词逐个可点；元素 `"\n"` 让原文额外换一行。字形是**内联 SVG**（`fill="currentColor"`），
  明暗主题自动适配、任意放大不糊，无需两套图。
- **词素索引由原文推导，且拆到基础词素**：句式（见「按词素找词」）是词素声明的唯一来源，
  构建时先把每个词的词素递归拆到只剩基础词素，再翻成「基础词素 → 词」的反向索引；
  目录页的词素筛选、词条页的「词素」区块都是预渲染好的（徽章带 `data-morpheme`，
  用来筛选的词表在页面数据里），JS 只做隐藏/显示与开合，不用 `fetch()`。
- **词头左右、正文上下**：词头是「左＝放大的外星字形（纯字形、不跳转）｜右＝中英释义」；
  正文是上方一整块原文、下方一整块译文（翻译标题 + 与原文行一一对应的中译）。
- **原文按字符网格排**：`""`＝一格宽的空白；换行与空行都恰好占**一格高**（`--gl-cell`，
  随字形尺寸自动缩放：正文 `--gl-row`、词头 `--gl-head`、目录卡片 `--gl-card`、徽章 `--gl-chip`），
  行与行之间不额外留缝；同一行里字符之间留 2px 的缝方便阅读。字形行是**行内排版**，
  放不下时浏览器自动折行，折出来的行行首空一格（见「原文写法」）。
- **id / 字形 / 英文释义解耦**：`<id>` 只作文件名与 URL，字形文件名走 `glyph`（缺省同名），
  英文释义走 `en`，三者可以各不相同。
- **pixel 模式无损**：源图是 1-bit 点阵，`png2svg.py` 只做「相邻墨点合并成矩形」，不插值不拟合
  （`one.png` 的 15 个墨点 → 1 个 `<rect>`）。
- **GNU Unifont 自动子集化**：正文用 Unifont（点阵字体，覆盖全部汉字），构建时扫描刚写出的产物
  得到精确字符集，5.1 MB 源字体裁到几十 KB；新增文本后重新构建即可。
  字体的 `@font-face` 单独放在 `web/static/fonts.css`，不经过打包器，路径原样相对
  `assets/`（`url("fonts/unifont.woff2")`），双击打开也取得到。
- **缺 SVG 时回退位图**：字形文件还没转 SVG 就先显示 PNG（`image-rendering: pixelated`），
  字形转换可分步做，站点始终可用。
- **构建可增量**：不整目录删除（Windows 下文件被占用会让全量删除中断），改成写完再清理多余产物；
  `--only <id>` 只重建指定词条，不会动别的页面。

## 与旧版（Jinja 模板 + Python 构建）的差别

站点换成了 Vue 3 + Vite，功能与外观保持不变，行为上有这几处调整（都是明确要求的）：

- **「括号包住的词不跳转」去掉了**：`(be)` 与 `be` 都是普通词，有词条就点得动。
- **「纯数字 token 不算实义词」去掉了**：数字也照常当词（没有词条就进「待补词条」）。
- **词素徽章不再显示英文**：徽章上只有字形 + 中译 +（数字），英文只在悬停提示与词条/卡片里出现。
- 词素句式的标记从 `of morpheme be` 简化为 `morpheme be`（旧写法仍然兼容，老数据无需改动）。
- **防剧透改成内置功能**：不再有 `data/lexicon.yaml` 里的 `spoiler:` 配置，页头按钮常驻，
  遮不遮只看浏览器里的状态（`localStorage`）。
- **左右词条链接遮着也点得动**：点一下直接跳转，不再先弹剧透警告（`data-spoiler-direct`）。
- **换行**：显式写的 `\n` 只是另起一行（行首不补空格）；而**自动折行**（一行放不下）的那一行
  行首空一个单位 —— 用「整行留一格左内边距 + 第一行负缩进」实现，只有折行受影响。

旧版的 `templates/*.j2` 与 `tools/build.py` 已被 `web/` + `tools/build.mjs` 取代；
`tools/png2svg.py`、`tools/subset_font.py` 保持不变（`png2svg.py` 依旧是画完字形后的第一步）。
